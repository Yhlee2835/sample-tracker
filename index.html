ASUS Sample Custody Tracker — 使用說明與 SOP 指南

1. 系統簡介 (System Overview)

專為展覽 (Computex, CES, IFA)、巡迴展與客戶拜訪設計，透過 Firebase RTDB 雲端即時庫存同步，提供全生命週期樣品履歷追蹤與保管權轉移 (Chain of Custody)。

核心功能：
  • 完整歷史履歷：每一次人員交接與跨活動調撥均自動記錄時間戳記與經手人。
  • 智慧配機 (SPM Mapping)：輸入需求機型即時對照帶入負責 SPM。
  • Teams 1-Click 催收：一鍵推播 Adaptive Card 提醒逾期或即將到期機台。
  • 客製化 Excel 匯出：支援全庫、當前篩選、逾期樣品或特定活動 2-Sheet 報表匯出。

2. 團隊角色與分工 (Role Matrix)

角色 (Role)主要職責 (Key Responsibilities)核心操作區塊
申請人 (CM)建立展覽活動、提交樣品借用需求、執行人員交接 (Handover)Events 頁面 + New Request
產品經理 (SPM)審核借機需求、登錄序號 (SN) 與顏色、確認派機數量、回收庫存Tracking 頁面 SPM Response
現場保管人 (Custodian)參展保管機台、維護樣品狀況、執行跨活動調撥 (Cross-Event Transfer)Tracking 頁面 Transfer

4. 標準作業流程 (Standard Operating Procedures)

SOP 1: 發起展覽活動與需求申請
1. 點擊 + New Event 填寫活動名稱、起訖日期與地點。
2. 於活動卡片點擊 + Request 選擇 Product Segment、Model、顏色與數量 (系統自動帶入主負責 SPM)。
SOP 2: SPM 審核、配機與派機出庫
1. SPM 於 Tracking 頁面點擊 SPM Response。
2. 選擇審核決策 (Fully / Partially Confirmed / Unavailable)，填寫 SN 序號與隨機配件後送出。
SOP 3: 現場人員交接與跨活動調撥
1. 於 Tracking 頁面點擊 Transfer。
2. 選擇 Handover (變更現場保管人) 或 Cross-Event Transfer (轉移至目標活動名下)，並點檢機況與配件。
SOP 4: 樣品歸還入庫與結案
1. 展期結束後點擊 Transfer。
2. 選擇 Reclaim (回收至 SPM 池) 或 Return (歸還倉庫)，狀態切換為 Returned 完成結案。
SOP 5: Teams 1-Click 催收與 Excel 報表匯出
1. 點擊 🔔 Ping 可直接發送 Teams Adaptive Card 催收逾期機台。
2. 點擊 Export 可依全庫、搜尋結果或指定活動匯出 2-Sheet Excel 報表。

5. 防呆機制與常見問題 (FAQ)

Overdue 警示：活動結束但機台尚未辦理歸還，請保管人儘速處理或點擊 🔔 Ping 發送 Teams 提醒。
一鍵重置：選取篩選條件時，點擊頂部 ✕ Reset 按鈕可即時還原預設清單。
